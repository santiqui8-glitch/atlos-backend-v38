## 0. RESUMEN EJECUTIVO
ATLOS V38 es frontend-only Vite + React 19 PWA version 38.0.0. No hay backend ni DB en repo. Habla con API externa https://atlos-api-production.up.railway.app con fallback hardcodeado en src/services/api.js:3. Tiene modo offline con IndexedDB + localStorage + cola atlos-queue + sync cada 60s.
Funciona como MVP demo pero pende de un hilo: App.jsx god-component de 329 lineas orquesta 10 vistas, 9 llamadas paralelas por refresh(), doble fuente de verdad localStorage+IndexedDB, auth JWT en localStorage, validacion solo frontend, config Vercel dudosa, sin tests/lint/TS/CI.
Conclusion: estable para demo, NO estable para escalar features sin estabilizar FASE 1-3.
